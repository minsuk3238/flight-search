# ✈️ 네이버 항공권 스마트 최저가 비교 & 추천 웹 (Flight Finder)

> 네이버 항공권 가격을 대상으로 내가 원하는 일정, 목적지, **원하는 탑승 시간대(출발/귀국)**를 지정하여 최저가를 비교하고 스마트하게 추천해주는 반응형 모던 웹 애플리케이션입니다.

---

## 🌟 핵심 주요 기능

1. **🕒 내가 원하는 시간대 정밀 필터링 (핵심 기능)**
   - 가는 편 출발 시간대 (예: `08:00 ~ 12:00`, `퇴근 후 18:00 이후` 등)
   - 오는 편 출발 시간대 (예: `15:00 ~ 21:00` 등)
   - 퀵 프리셋 버튼 (오전, 오후, 퇴근 후 저녁) 및 시간 직접 기입 지원

2. **✈️ 항공사 목록화 및 구분 (FSC / LCC / 외항사)**
   - **대형 국적기(FSC)**: 대한항공, 아시아나항공
   - **국내 저비용(LCC)**: 제주항공, 진에어, 티웨이, 에어부산, 에어서울, 에어로케이, 이스타항공
   - **외국 항공사**: 피치항공, 일본항공(JAL), 전일본공수(ANA), 비엣젯, 싱가포르항공 등
   - 각 항공사별 **실시간 최저가 금액** 및 **무료 수하물 포함 여부** 표기 & 다중 선택 필터링

3. **🏆 AI 스마트 추천 3대 핵심 픽**
   - 💰 **초특가 최저가 (Best Price)**: 가장 저렴한 가성비 항공편
   - ⚡ **황금 시간대 직항 (Best Schedule)**: 아침 일찍 출발 & 꽉 찬 일정의 최적 스케줄
   - 🌟 **AI 종합 가성비 픽 (Best Value)**: 가격, 소요시간, 수하물, 시간대 편의성을 종합한 만족도 1위

4. **📊 기간별 최저가 비교 캘린더 (±6일 트렌드 차트)**
   - 선택한 일정 전후 총 13일간의 날짜별 최저가를 바 차트로 시각화
   - 어떤 요일/날짜가 가장 저렴한지 한눈에 비교하고, 바를 클릭하면 해당 일정으로 즉시 전환

5. **🔗 친구에게 검색 조건 원클릭 공유**
   - 설정한 조건(출발지, 도착지, 날짜, 시간대 범위, 항공사 필터 등)이 URL 파라미터로 자동 연동
   - **[친구에게 공유]** 버튼으로 링크 및 메신저/카카오톡용 요약 텍스트를 원클릭 복사

6. **🔗 네이버 항공권 바로 예약 연동**
   - 검색된 항공편 카드에서 **[네이버에서 예약]** 클릭 시 네이버 항공권 실제 조회/예약 페이지로 즉시 이동

## 🚀 빠른 시작 방법 (로컬 실행)

```bash
# 1. 의존성 패키지 설치
npm install

# 2. 개발 모드 실행 (프론트엔드 + 백엔드 동시 구동)
npm run dev

# 브라우저 접속: http://localhost:5173
```

## 🌐 친구와 웹으로 공유하는 무료 배포 가이드

친구들이 언제 어디서든 브라우저 URL로 접속할 수 있도록 원클릭 무료 배포를 지원합니다:

### 방법 1: Render / Railway 배포 (추천)
1. 코드를 GitHub 저장소에 Push합니다.
2. [Render.com](https://render.com) 접속 ➔ **New Web Service** 생성
3. Build Command: `npm install && npm run build`
4. Start Command: `node server/index.js`
5. 발급된 `https://your-app.onrender.com` 링크를 친구들에게 공유하면 끝!

### 방법 2: 로컬 프로덕션 실행
```bash
npm run build
npm start
# http://localhost:5000 접속
```
